# SENTINEL · 守望

一个看起来像普通智能家居营销站点的单页恐怖体验。随着向下滚动，文案、界面和摄像头画面会逐渐失控，最后变成一段第一人称的入室恐怖场景。

> ⚠️ 内容提示：包含突发惊吓画面、闪烁与低频音效。建议在安静环境中佩戴耳机体验；对强光、闪烁或恐怖内容敏感者请谨慎观看。本页为虚构创作，不包含真实监控、摄像或数据采集功能。

## 运行

无需构建、无需联网、无第三方依赖。

```bash
cd D:\cyh\ai训练\恐怖网站\deepseek
python -m http.server 8080
```

打开 <http://127.0.0.1:8080>。

也可以直接双击 `index.html`（音效需要一次点击后才会启动，部分浏览器在 `file://` 下会限制音频）。

## 体验结构

1. **0–25%** — 一个正常的全屋安防营销站：品牌、功能、安装流程、用户评价。
2. **25–45%** — 实时摄像头演示区。走廊机位里多了一个人；状态栏开始说一些不该由客服说的话。
3. **45–60%** — 价格、FAQ、页脚逐个变味，客服窗口自己弹出来。
4. **60–75%** — 黑屏独白。页面开始直接和观看者说话。
5. **75–100%** — 一段实时家用摄像头画面：有人从走廊深处走近。信号中断后，屏幕上出现别的东西。

网页底部有「重新开始」按钮。建议第一次不要快速滚动。

## 文件结构

```
index.html            页面与全部中文文案
css/style.css         视觉系统、布局、恐怖阶段的样式
js/main.js            滚动编排、异变、摄像头场景、最终惊吓
js/cameras.js         Canvas 2D 伪造的 CCTV 监控画面（4 个房间）
js/audio.js           WebAudio 合成音景（无音频文件）
preview/              桌面端截图预览
```

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript，无构建步骤、无外部字体或图片。
- 所有摄像头画面由 Canvas 2D 实时绘制，包含噪点、扫描线、时间码、故障切割与人形剪影。
- 所有音效由 WebAudio 振荡器与噪声实时合成；页面加载后保持静音，直到点击「开启声音」。
- `prefers-reduced-motion` 下会减少闪烁与位移动画。
- 画面中所有品牌、人物、评价与事件均为虚构。

## 开发/验收模式

在 URL 后加 `?qa=1` 会强制显示滚动入场元素并暂停装饰动画，方便截图；`?qa=1&to=%23intrusion&off=1500` 可以直接跳到某个场景位置。正常访问不受影响。
